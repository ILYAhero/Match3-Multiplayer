# Уютный мир · набор ассетов v0.1

Для проекта `ILYAhero/Match3-Multiplayer` (Danash).

**Статус:** локально подготовленный набор из 44 PNG. Это первый экспорт из пяти утверждённых концепт-листов, а не весь готовый интерфейс игры. Репозиторий не удалось прочитать; его структура и версия Unity не проверены. Коммит, ветка и pull request не создавались. Unity Editor здесь не запускался.

## Что есть в наборе

- 5 основных фишек: сердце, звезда, капля, лист, цветок. Ещё 3 изображения лежат в `Alternates`: яблоко, оранжевая сфера и кристалл.
- 6 спецфишек: две ракеты, бомба, радужная сфера, крест и прицельная ракета.
- 4 иконки усилителей на синих кнопках; 6 препятствий, включая две стадии льда.
- 3 элемента клетки: пустая основа и два отдельных контура выделения.
- 14 элементов UI: пустые кнопки, деревянная плашка, панель, слоты, переключатель, настройки, звук и подсказка.
- 3 индикатора состояния сети.

PNG имеют прозрачный фон. Большинство игровых иконок уложено на холст 128×128; это **не означает 128 пикселей исходной детализации самого объекта**. Нативные изображения из концепт-листов обычно меньше. Искусственное увеличение до 512 или 1024 не выполнялось. Размеры, координаты исходных фрагментов, прозрачные поля, статус обработки и контрольные суммы указаны в `asset_manifest.json`.

## Как открыть в Unity

1. Сделайте отдельную рабочую ветку, например `art/cozy-world-assets`, из вашей актуальной ветки разработки. Существующая схема веток не проверена; это только предлагаемое название.
2. Скопируйте папку `Assets/CozyWorld` из ZIP в папку `Assets` проекта. Сохраните все `.meta`. Остальные папки ZIP предназначены для документации и воспроизведения экспорта.
3. Дождитесь завершения импорта и компиляции редакторских скриптов. Откройте `Tools → Cozy World → Asset Gallery`.
4. Откройте `Tools → Cozy World → Validate Imported Sprites`. Если текстуры не стали спрайтами, выполните `Reapply Pack Import Settings`. Эта команда затрагивает только папку пакета и сначала запрашивает подтверждение.
5. Проверьте фишки на реальном поле 9×9 и устройстве. Только затем добавляйте материалы, префабы и привязки к игровой логике.

Вместо копирования можно импортировать прилагаемый `.unitypackage`: он содержит ту же папку `Assets/CozyWorld`. ZIP дополнительно содержит пять оригинальных концепт-листов и инструменты экспорта. Не импортируйте две разные копии пакета в разные папки: GUID намеренно стабильны.

## Безопасность интеграции

Пакет не заменяет сцены, `ProjectSettings`, `Packages/manifest.json`, сетевой код или игровые скрипты. В нём нет исполняемого кода матча и автоматического изменения открытой сцены. Редакторские скрипты работают только внутри `Assets/CozyWorld/Art/Sprites/`. Исходные концепт-листы находятся вне `Assets`, чтобы не включать их в игровой билд случайно.

Имена и GUID спрайтов стабильны: при последующей замене на отрисовку высокого разрешения сохраните `.meta`. Не создавайте новый GUID без необходимости. Шрифты, сторонние плагины и покупки не добавлены.

## Что требует дальнейшей работы

Это не послойный экспорт из Figma/PSD: исходники — пять плоских сгенерированных изображений. Некоторые границы обтравлены автоматически, кнопки без текста и состояния клетки реконструированы. Для финального выпуска нужны проверка краёв на тёмном и светлом фоне, согласование размеров и отрисовка крупного UI в нужном разрешении. Контуры выделения имеют собственные прозрачные поля: при наложении ориентируйтесь на `visible_bounds_ltrb`, а не только на размер PNG.

Два спрайта льда — непрозрачные **иконки препятствий**, а не прозрачная ледяная оболочка поверх фишки. Четыре усилителя экспортированы вместе с синей кнопкой. Переключатель `ui_toggle_on` — цельное изображение, не интерактивный контрол. Нет анимаций, аудио, VFX, атласов, аватаров без фона, высокодетальных фонов, готовых экранных префабов или сетевых привязок. Системные состояния, вход в комнату и реванш описаны в документации, но не реализованы этим арт-пакетом.

Сетка на некоторых концепт-листах не соответствует 9×9. Эти изображения являются визуальными референсами, а не точной спецификацией геометрии. Сохраняем требования проекта: общее поле 9×9, одновременный режим и пошаговый режим с 5 секундами на ход. Открытие меню в онлайн-матче не должно само по себе останавливать общий таймер. Не используйте обещание «прогресс будет сохранён» из концепта окна выхода без соответствующей реализации.

## Навигация по файлам

`Assets/CozyWorld/Art/Sprites/` — отдельные PNG и `.meta`.

`Assets/CozyWorld/Editor/` — импортёр, галерея и проверка импорта, только для Editor.

`Assets/CozyWorld/Data/` — манифест с происхождением каждого спрайта и предложенные дизайн-токены.

`Documentation/CozyWorld/AssetGallery.html` — автономная галерея с поиском, светлым/тёмным фоном и отдельными PNG. Интернет и сервер не нужны.

`Documentation/CozyWorld/UI_INVENTORY.ru.md` — состав интерфейса и статус готовности.

`Documentation/CozyWorld/ReferenceSheets/` — пять исходных концепт-листов, не игровые текстуры.

`Tools/CozyWorld/` — воспроизводимый экспорт и проверка файлов. Эти Python-инструменты не нужны для обычного импорта в Unity.

## Проверки и источники API

Проверены наличие всех PNG, режим RGBA, прозрачные края холста, уникальность GUID, соответствие размеров и SHA-256 манифесту, читаемость JSON/YAML и целостность архивов. Выполнена визуальная проверка листа с экспортами. Это не заменяет запуск Unity, сборку приложения, проверку GPU или тест сети.

Настройки импортёра сверялись с официальным API Unity 6.0. Версия целевого проекта неизвестна; компиляция C# в Unity не выполнялась.
